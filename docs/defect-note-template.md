# Defect note: <short title>

## Impact

Who or what was affected, for how long, and what was not affected?

## Detection

What signal revealed the problem? Include request IDs and failing test names, but no secrets.

## Timeline

Record only material observations and actions with times.

## Root cause

Explain the causal mechanism. Avoid restating the symptom.

## Contributing conditions

What made the defect easier to introduce or harder to detect?

## Corrective change

Link the minimal code, contract, test and documentation changes.

## Verification

Show the failing test before the change, the passing suite afterwards and any manual check.

## Prevention

Name the durable control: test, review rule, lint rule, compatibility check, alert or design change.
